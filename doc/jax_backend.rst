:mod:`ikpy.jax_backend` module
----------------------------------------

Optional JAX backend providing JIT-compiled kinematics and inverse kinematics
with analytical Jacobians computed via automatic differentiation.

Requires the ``jax`` extra: ``pip install 'ikpy[jax]'``.
